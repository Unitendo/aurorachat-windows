<h1 align="center">How to build aurorachat</h1>

Install Rust and Cargo, and then run the following commands:
```sh
git clone https://github.com/Unitendo/aurorachat-windows
cd aurorachat-windows
cargo build --release
```
After the build completes successfully, the `.exe` file should be in `aurorachat-windows/target/release/`
